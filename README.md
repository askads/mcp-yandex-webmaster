# mcp-yandex-webmaster

MCP-сервер для [Яндекс Вебмастера](https://webmaster.yandex.ru) — индексация, поисковые запросы, sitemap, диагностика сайта и внешние ссылки из Claude, Cursor, Codex и других AI-клиентов.

> 🚧 В разработке.

## Семейство mcp-yandex-*

- [mcp-yandex-direct](https://github.com/askads/mcp-yandex-direct) — контекстная реклама
- [mcp-yandex-metrica](https://github.com/askads/mcp-yandex-metrica) — веб-аналитика
- [mcp-yandex-wordstat](https://github.com/askads/mcp-yandex-wordstat) — статистика поисковых запросов
